# Бот-счётчик постов админов канала

Считает, сколько постов опубликовал каждый админ Telegram-канала.

## Запуск

1. Создай бота в @BotFather, возьми токен.
2. `cp .env.example .env` и вставь токен.
3. `pip install -r requirements.txt`
4. `python bot.py`

## Настройка канала

- Добавь бота в канал **администратором**.
- Включи в канале **«Подписывать сообщения»** (Sign messages). Без этого Telegram не передаёт боту автора поста, и все посты попадут в «Без подписи».
- Считаются только посты, опубликованные **после** добавления бота.

## Команды (в личке с ботом, только для админов канала)

- `/channels` — список каналов и их id
- `/top [day|week|month|all] [id канала]` — посты по админам
- `/total [day|week|month|all] [id канала]` — всего постов

Если канал один, id указывать не нужно.

## Особенности

- Альбом из нескольких фото/видео считается за один пост.
- Админы различаются по подписи (имя в профиле). Если админ сменит имя, он будет считаться новым автором.
- Редактирование постов не учитывается.
